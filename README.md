Spam Message Classifier

Project Description

This project uses Machine Learning to identify whether an SMS message is Spam or Not Spam.

Technologies Used

- Python
- Pandas
- Scikit-learn
- TF-IDF Vectorization
- Multinomial Naive Bayes
- Google Colab

Dataset

The project uses the SMS Spam Collection dataset from the UCI Machine Learning Repository.

Model

- TF-IDF for text feature extraction
- Multinomial Naive Bayes for classification

Model Accuracy

96.71% (observed during the model evaluation run).

Features

- SMS data preprocessing
- Spam and Not Spam classification
- Model evaluation
- Custom message prediction
- Interactive message testing

How to Run

1. Open the notebook in Google Colab.
2. Run all code cells.
3. Enter an SMS message.
4. View the prediction.
